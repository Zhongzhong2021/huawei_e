# 核心特征与候选关系的复现

本说明对应统一读取采用的核心流程：原素材审计、原生特征、选择性词级候选与局部互证、物理时间索引及全100条汇总。第1–5节说明原生特征与基础关系，第6节说明Whisper和局部MFA增强流程。自动生成不读取人工记录。

## 1 准备环境与固定模型

使用Python 3.10，并在系统路径中提供FFmpeg和FFprobe。实际环境版本记录在`config/environment.txt`及运行日志中。示例命令在项目目录执行：

已实测的FFmpeg和FFprobe版本为4.4.2-0ubuntu0.22.04.1；`data/runtime_environment.json`同时记录Python、关键包及工具版本，不记录主机名、用户名或环境变量。新重建入口首先运行`record_environment.py`生成本次环境记录。

Ubuntu 22.04中若尚未安装系统依赖，先执行`apt-get install python3.10-venv ffmpeg libgl1 libglib2.0-0`（需要系统安装权限），然后创建独立环境。

```bash
python3.10 -m venv .venv
.venv/bin/python -m pip install --extra-index-url https://download.pytorch.org/whl/cpu -r config/environment.txt
.venv/bin/python scripts/fetch_core_models.py --cache /绝对路径/model-cache
```

模型清单为`data/models.json`，每个文件均有固定URL及SHA256。获取脚本复用摘要一致的缓存；已有文件摘要不符时终止，不静默覆盖。预训练工具权重体积较大，不进入50MB特征提交包。首次下载需要网络；实际重建设置离线模式，仅使用已校验缓存。

上述安装步骤已在新的独立Python虚拟环境中实测通过，未启用系统site-packages；锁定包版本逐项匹配且`pip check`通过。随后从交付ZIP解压出的代码重建了全部100条，3100个数组及两层自动决策完全一致，见`data/clean_environment/verification.json`及安装日志。此次复用了已逐文件验证SHA256的模型缓存，系统、硬件和FFmpeg保持相同；该重复性结论对应上述系统与硬件条件。

## 2 全量重新生成

```bash
.venv/bin/python scripts/rebuild_core.py \
  --source /绝对路径/附件1-数据集原始多模态样本 \
  --models /绝对路径/model-cache \
  --output /绝对路径/新的重建目录
```

`--source`目录应含唯一的`label-100.xlsx`及全部100个原视频。`--output`必须不存在，避免覆盖现有实验和记录。此命令实际重新解码并推理全部样本，依次执行：

1. `audit.py`：源身份、文本标签、音视频时钟及PCM完整性。
2. `extract.py`：100条原生特征及原采样率审核WAV。
3. `run_automatic_alignment.py`：重新识别与选择性候选决策。
4. `run_local_evidence.py --corroborated`：保留基础结果，按分离片段互证恢复局部候选。
5. `build_temporal_index.py`：真实支持和逐维有效性下的音视频索引。
6. 两个核验脚本：物理索引公式及自动关系读取。
7. `build_delivery_summary.py`：统一全100条表。

每步标准输出和错误写入新目录`data/logs`，`data/core_rebuild.json`保存命令、耗时、退出码及摘要。失败时停止执行并保留日志；排查后使用新的输出目录重新运行。

## 6 连续语音与多粒度增强

增强流程在已核验的原生特征和基础关系上运行。读取使用`multigranular_reader.Dataset`，基础对照使用`delivery_reader.Dataset`。增强结果、词组粒度及指标定义见正文第4.3、7.6–7.8节。

准备独立Whisper环境与固定权重；MFA使用Linux锁定环境和固定模型：

```bash
python3.10 -m venv /绝对路径/whisper-env
/绝对路径/whisper-env/bin/python -m pip install -r config/whisper_environment.txt
/绝对路径/whisper-env/bin/python scripts/fetch_whisper_model.py --output /绝对路径/whisper-model

.venv/bin/python scripts/fetch_acoustic_models.py --cache /绝对路径/mfa-models
```

MFA安装后以`/绝对路径/mfa-env/bin/mfa version`核对3.3.9。增强分支实测为RTX 4060、CUDA int8_float16；Whisper环境锁定文件包含cuBLAS、cuDNN等依赖。统一入口自动从所给Whisper环境中设置动态库搜索路径。

```bash
.venv/bin/python scripts/rebuild_multigranular.py \
  --core /绝对路径/已完成的基础重建目录 \
  --source /绝对路径/附件1-数据集原始多模态样本 \
  --whisper-python /绝对路径/whisper-env/bin/python \
  --whisper-model /绝对路径/whisper-model \
  --mfa-prefix /绝对路径/mfa-env \

  --output /绝对路径/新的增强重建目录
```

`--core`也可指向已解压且核验通过的交付目录。该命令复制原生特征和基础关系，重新执行100条无提示识别、局部候选生成、236个音素对齐任务、多粒度决策及读取检查。运行记录保存于新目录`data/multigranular_rebuild.json`，每一步有退出码与日志摘要。输出目录必须不存在。`--device cpu`可切换为int8 CPU推理；本文实测与重复性结论对应CUDA配置。

在相同操作系统和硬件上使用独立Whisper环境及固定MFA环境，新目录完整重跑的100条识别内容、时间、分段和最终关系与交付结果一致。固定权重缓存复用；详情见`data/multigranular_alignment/reproduction.json`及所附日志。
