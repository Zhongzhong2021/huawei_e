## 克隆后检查现有结果

需要Git和Python 3.11；以下命令在终端依次执行。创建并激活虚拟环境后安装读取依赖即可，无需GPU或原视频。

```bash
git clone https://github.com/Zhongzhong2021/huawei_e.git
cd huawei_e/问题1
python -m venv .venv
```

Linux/macOS激活：`source .venv/bin/activate`；Windows PowerShell激活：`.venv\Scripts\Activate.ps1`。

```bash
python -m pip install -r requirements-reader.txt
python scripts/verify_manifest.py
python scripts/q1v6_reader_check.py --features features
python scripts/q1_final_audit.py --features features --output interface_check_new
python external_validation/verify_external.py features/samples
```

期望100条样本、1948词、7905个100 ms网格位置；填充和文件摘要检查通过。公开对照复算检查1348条参考记录、38174个声音帧和7728个视觉位置；其中1347词满足原实验的比较条件，记录数与有效比较数有区别。

## 继续修改或完整重建

文字编辑从“问题一_正文.md”开始；核心读取与汇聚代码为scripts/q1v6_features.py，字段定义见input_contract.json和features/protocol.json。修改方法后将新结果写入独立目录，保留本版结果用于比较。

从原视频重建还需要题目附件一、Docker及NVIDIA GPU支持，并下载固定通用模型。将.env.example复制为.env，改为当前机器的数据目录；详细构建及运行步骤见README.md。原视频、大型模型权重、运行缓存未上传；本目录附带的YuNet小型模型及许可证用于既有Docker流程。

问题1与问题2使用各自环境和接口。本问自建词级特征不能仅凭同名字段或同为768维就直接替换问题2的数据。

## 文件校验与历史材料

manifest.sha256.json校验本次Git上传内容，scripts/verify_manifest.py可在任何工作目录运行。metadata/original_package_*保存此前30.32 MB资料包的摘要与清单，供历史追溯；该ZIP没有重复上传，不能把历史包摘要当作当前仓库快照摘要。

完整候选研究档案不随本次同步：method_choice只有方法取舍及统计摘要。主特征读取、公开记录复算和主处理链代码均已随仓库提供。

如修改了被校验文件，校验失败会指出具体路径；应在核实修改和重新验证后更新清单，不应跳过核验。复算公开统计可能重写其记录文件，这是命令说明中明确的输出行为。
