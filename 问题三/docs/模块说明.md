# 模块说明

## 运行路径

入口 [run.py](../run.py) 暴露 `predict`、`evaluate`、`train`。默认从脚本所在目录查找配置、统计、策略和权重，因此整个 `问题三` 目录可搬移；`predict --bundle` 也能指向新训练的 `best/<目标>`。预测过程读取对齐样本、构造窗口批次、建立模型、以 `strict=True` 加载完整检查点、应用冻结策略，最后写 CSV；主模型还写 JSONL 原生解释。评价使用预测表中标签或显式标签表，不重新选策略。训练读取 train/valid，重算训练集统计，按三个验证目标分别保留最佳模型。

| 位置 | 用途 |
|---|---|
| `q3b/data.py` | 校验比赛对齐 pickle，计算只用 train 的均值/尺度，识别有效模态位置，打包窗口及来源索引 |
| `q3b/bert_init.py`、`q3b/bert_model.py` | 本地 BERT 结构与初始化；预测时仅构建结构，训练时读取独立提供的原始预训练权重 |
| `q3b/model.py` | 三模态局部项和显式成对交互的低秩计算 |
| `q3b/ordinal_uncertainty.py`、`q3b/native_next.py` | 主模型分类、回归、多模态不确定性融合与可分解读出 |
| `q3b/selfmm_adapter.py`、`q3b/native_selfmm.py` | SELF-MM 思路的本地比赛适配 |
| `q3b/tetfn_source_adapter.py`、`third_party/MMSA/` | TETFN 适配入口与保留的 MMSA 网络组件 |
| `q3b/experiment.py`、`q3b/multiobjective.py`、`q3b/train.py` | 训练、验证策略搜索、三目标最优保留、指标计算 |
| `scripts/explanations.py`、`scripts/native_record.py` | 主模型原生贡献核算、成对交互均分与关键位置提取 |
| `weights/<模型>/` | `best.pt`、`config.json`、`stats.json`、`policy.json`、`selection.json` |
| `results/<模型>/` | 已冻结的验证/测试/附件4结果、训练历史和指标 |
| `paper/` | Word 论文、源 Markdown、图和再生脚本 |

## 判定与解释口径

主模型 `uncertainty` 的冻结策略是 `classification` 且中性类 logit 加 `-0.4`，最终分类取最大值；两个基线的冻结策略为 `regression`，根据验证集选得的上下阈值分三类。三个模型的最终强度均把 `raw_intensity` 限在 [-3,3]，并与最终类别符号对齐；中性强度固定 0。因此报告 MAE 是最终强度 MAE，不能混成 raw 回归误差。

主模型的分类解释把预测类与最强竞争类的校准 logit 之差分解为偏置、文本、音频、视觉项；成对项各分一半给两个模态。绝对净分数归一得到各模态份额。若解释回归通道，目标为预激活 `q`，两种贡献量不可直接相比。精度权重指融合可靠性，不是贡献；单模态残差方差也不是最终区间。局部证据来自上下文中的窗口读出，可定位输入位置，但不声称独立的因果效应。

当前交付是针对比赛对齐特征、标签与三类指标的适配实现，**不是 SELF-MM 或 TETFN 原论文的严格复现**。上游代码用途、许可证和本地修改清单见[模型来源与复现实验说明](模型来源与复现实验说明.md)、[第三方声明](../THIRD_PARTY_NOTICES.md)及 `../licenses/`。
