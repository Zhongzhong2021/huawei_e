# 环境配置

## 运行环境

已验证环境是 Python 3.11.15、PyTorch 2.5.1+cu124、Transformers 5.15.1、NumPy 2.4.6；GPU 为 NVIDIA RTX 3090 Ti。核心依赖固定于 `../requirements.txt`。训练单轮记录的 GPU 峰值分配约 2.9×10⁹ 字节，但对齐数据和预处理批次还占系统内存，建议至少 16 GB 内存。CPU 可以推理，速度较慢。

以下命令在搬移后的 `问题三` 目录执行，二选一安装 PyTorch 后再装其余固定依赖。Python 3.11 建议通过 `conda create -n q3-delivery python=3.11` 或等效虚拟环境取得。

```bash
# CPU
python -m pip install --index-url https://download.pytorch.org/whl/cpu 'torch==2.5.1'
python -m pip install -r requirements.txt
```

```bash
# NVIDIA GPU：适用于驱动支持 CUDA 12.4 的环境
python -m pip install --index-url https://download.pytorch.org/whl/cu124 'torch==2.5.1'
python -m pip install -r requirements.txt
```

先装对应的 PyTorch wheel，`requirements.txt` 中的 `torch==2.5.1` 随后保持同版。验证：

```bash
python -c 'import torch, transformers, numpy; print(torch.__version__, transformers.__version__, numpy.__version__, torch.cuda.is_available())'
python run.py --help
```

论文再生和交付测试的额外依赖放在 `requirements-report.txt`、`requirements-dev.txt`：

```bash
python -m pip install -r requirements-report.txt
python -m pip install -r requirements-dev.txt
```

本机实测 `matplotlib==3.11.1`、`python-docx==1.2.0`、`pytest==8.4.2`。这两份附加清单不影响正常预测。

## 获取交付目录

Git 方式：先安装 Git LFS，克隆后在克隆目录拉取三个权重；合计约 1.3 GB，确认 `weights/{uncertainty,selfmm,tetfn}/best.pt` 是实际二进制文件，而非几行 LFS 指针。

```bash
git lfs install
git clone https://github.com/Zhongzhong2021/huawei_e.git q3-delivery
cd q3-delivery
git lfs pull
cd 问题三
```

若收到的是包含实际权重的完整归档：

```bash
tar -xzf /path/to/问题三_完整交付.tar.gz
cd 问题三
```

本交付的完整归档可在包目录用以下命令再生，输出放在包目录外，并生成清单与 SHA-256：

```bash
python tools/package_delivery.py --archive ../问题三_完整交付.tar.gz
python tools/package_delivery.py --verify
```

校验逐文件哈希并检查权重不是 LFS 指针。仅 `git archive` 生成的归档可能含 LFS 指针，不能当作完整权重归档。目录可搬到任意位置，运行时从 `run.py` 自身定位 `assets/`、`weights/`，不依赖原仓库绝对路径。

## 数据与离线行为

比赛对齐数据未随目录分发。推荐位置是 `data/aligned_50.pkl` 和 `data/attachment4_aligned/01.pkl` … `20.pkl`。`data/` 与自建 `output/` 应排除版本控制。只反序列化可信来源的比赛 pickle 文件，因为 Python pickle 可执行文件内代码。

预测可用 `HF_HUB_OFFLINE=1` 禁止网络探测。随包只有 BERT 配置，所有三种 `best.pt` 含完整任务模型参数，并以 `strict=True` 读取；无需另下载原始 BERT 权重。重新**训练**则必须另行准备原版 `bert-base-uncased` 的本地 `config.json` 与单文件 `model.safetensors`（或 `pytorch_model.bin`）。详见[复现实验说明](模型来源与复现实验说明.md)。
