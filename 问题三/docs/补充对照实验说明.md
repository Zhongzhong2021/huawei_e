# 原生结构与较弱参数配置的补充对照

本次按用户要求补充较弱模型及参数结果，使用既有实验记录，未新增训练、改变主模型或替换开源基线。论文第6.3节增加完整结构对照，第6.4节增加两组完整学习率试验；保留SELF-MM、TETFN及补充对照中较好的配置，使比较的范围和取舍可审查。

## 对照的选择方式

结构表覆盖同一原生骨干上有序分类头和不确定性融合的全部四种开关组合。包含联合监督基础、仅有序头、两模块同时开启和本文主模型，而不是只列两个较差的有序设置。四者种子17、基础学习率、其他公共训练参数相同，训练上限20轮、早停耐心4轮，统一取各自验证Macro-F1最优轮次和策略。

学习率表覆盖两个既有参考配置的0.5/1/2倍试验。A组为默认监督权重，B组为较强分类监督；组内同时改变BERT和其他层学习率，模型参数以及其余训练参数相同。训练上限20轮、耐心6轮、种子17，全部行均报告各配置自己的验证Macro-F1最优记录。配置名含`mae`仅表示最初细化时父配置的来源；本次表内仍统一读取`winners.json`中的`macro_f1`，不混用最优目标。

B组2倍学习率是较弱参数案例，验证Acc/Macro-F1/MAE为0.609890/0.604246/0.591165；不能由这一联合变化拆解两个学习率的独立作用。A组默认配置和B组参考配置也均保留，其中B组Macro-F1更高、MAE更差，不宣称当前主模型在全部指标上最优。

核验流程：逐文件核对原检查点SHA256，使用交付代码严格载入完整状态；验证重放与原NPZ的类别、raw和logit完全一致（8组最大差0），从原输出重算三项指标与存档完全一致；然后原样应用冻结策略到测试集。本次不读取附件四数据或标签。S5/T1在本次重放中的验证和测试指标与已交付20轮上限参考结果一致，其余参数配置不能据此视为已训练20轮。

SELF-MM的S0、S1、S3、S4测试Macro-F1与MAE均弱于S5，S3的测试Macro-F1为0.6187、MAE为0.6252。S2的测试准确率69.60%、Macro-F1为0.6515，则略高于主模型；T0虽验证较弱，测试Macro-F1为0.6513，也高于T1。论文保留这些完整结果，区分验证与测试排序，未据测试分数重新挑选基线。S4/S5同时改变分组学习率和衰减，T0/T1同时改变BERT学习率和多处Dropout，均不作单参数因果归因。
