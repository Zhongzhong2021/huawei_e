# 图表字体

`Q3PaperSans.otf`是本稿图表所需字符的字体子集，改名为Q3 Paper Sans。源字体为NotoSansCJKsc-Regular.otf，来自[Noto CJK](https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf)，SIL Open Font License 1.1，许可见[许可证](../../licenses/NotoSansSC-OFL.txt)。子集由fontTools生成，仅用于可重复绘制中文图表；SVG已将字形转为路径。

Word正文使用宋体、黑体、Times New Roman，公式使用Word数学对象；这些系统字体不随包分发。缺少相应系统字体的软件会进行字体替换，分页可能略有差别。
