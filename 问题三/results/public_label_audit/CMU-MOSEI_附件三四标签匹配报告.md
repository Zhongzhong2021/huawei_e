# 附件三、四与 CMU-MOSEI 公开源标签匹配核验

已为附件三 30 条、附件四 20 条样本找到唯一公开源样本，共 50 条。
这里的情感值是公开 CMU-MOSEI 源数据标签，不是模型预测，也不是另行取得的竞赛官方答案文件。

## 数据范围与来源

使用 MMSA 的完整 CMU-MOSEI 50 步对齐特征版本及完整文本标签表；不包含原始视频音频全集或非对齐版本。
文本标签表 22,856 条，公开原始划分为 {'train': 16326, 'valid': 1871, 'test': 4659}。
数据下载自固定版本的公开 Hugging Face 镜像；完整对齐包摘要与 MMSA 官方 README 公布的 SHA-256 对照。
来源：[MMSA 官方数据说明](https://github.com/thuiar/MMSA#2-datasets)、[对齐包与文本标签镜像](https://huggingface.co/datasets/tamb2203579/CMU-MOSEI/tree/f7dba7c24793fa9ed11c5063521f3acdc22bd9c6)、[SDK 文件镜像](https://huggingface.co/datasets/reeha-parkar/cmu-mosei-comp-seq/tree/5f8d513c34278006d27f98e5609564e6d4b353d7)。
完整对齐包 SHA-256：`45eccfb748a87c80ecab9bfac29582e7b1466bf6605ff29d3b338a75120bf791`。每个下载文件均保存来源 URL、大小与摘要。
SDK 标签及词时间戳文件来自镜像，官方 SDK 的文件地址已核实；官方下载主机当前不可用。

## 匹配方法与核验结果

1. 附件四使用完整 raw_text 逐字匹配，再核对 BERT 序列；20 条均只有一个逐字匹配。
2. 附件三没有原文与源 ID。将 UNK（词元 100）视为缺失通配符，保持其余词元原位置、注意力掩码和有效长度；30 条均只有一个候选。没有用去掉 UNK 后的残句作模糊匹配。
3. SDK 标签按同一视频内片段编号的字符串顺序对应，先检查片段数和整个视频全部标签一致，再读取目标行；另用带时间戳词序列交叉核验文本。
SDK 标签核验通过 50/50；目标片段文本在该视频内唯一相似度最高 50/50。词时间戳转录会缺词或包含相邻边界词，相似度仅作辅助证据。
完整对齐特征核验：已执行；通过 50/50。
完整对齐包与文本标签表的全量对应审计：{'samples': 22856, 'source_id_found': 22856, 'verbatim_text_equal': 22856, 'labels_equal': 22856, 'split_equal': 22856}。
完整特征核验对附件四比较原文、BERT 及文本/音频/视觉特征；对附件三比较保留词元及非零音视频特征。音视频比较先转换为附件数据类型，再比较数值。全零模态不作为独立确认依据。

附件二源数据审计：{'samples': 4850, 'source_id_found': 4850, 'verbatim_text_equal': 4850, 'labels_equal': 4850}。
本次 50 条与附件二的同片段 ID 重合数：9。公开原始划分与附件二比赛划分分别保存，不能混为一谈。

恢复样本在公开源数据中的划分：{'test': 50}；与附件二重合样本的比赛划分：{'test': 9}。

## 使用范围与复现

本次标签单独保存，没有加入训练集、用于调参或覆盖既有预测。今后若利用这些标签评估附件三/四，应标为公开源标签核验，不能再把据此优化后的结果称为未见标签的盲测表现。
附件四没有中性样本，不能据此评价中性类别识别能力；样本量小，不宜替代附件二测试集的整体性能评价。

复现命令：

```bash
python scripts/download_cmu_mosei_aligned.py
python scripts/match_cmu_attachments.py --full
```

机器可读结果：`attachment3_public_labels.csv`、`attachment4_public_labels.csv`、`public_source_label_matches.json`。JSON 另含 SDK 时间区间、词序列、特征核验明细和附件二重合审计。
分词器为缓存的 bert-base-uncased（版本 86b5e0934494bd15c9632b12f734a8a67f723594）；HDF5 读取依赖 h5py，当前安装于数据目录的 python_deps。每条附件输入的 SHA-256 记录于 JSON。
完整数据位于 `data_external/cmu_mosei_full/`（指向 RAID 磁盘）。来源清单见该目录的 `*.provenance.json`。


本文件为历史实验溯源记录；其中根目录scripts与runs路径属于研究工作区。当前独立交付的操作入口以../../docs/详细使用指南.md为准。
