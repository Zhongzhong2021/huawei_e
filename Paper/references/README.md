## 采用与取舍

本规划采用三种组织方式：共用概念集中定义；各问顺着任务、变量、求解和验证展开；摘要给具体方法与主要数值。采用结果图与解释相邻的布局，针对同类对照优先组合子图。

旧论文中的目录、字体、表格形式和摘要长度不覆盖本届规范。论文中的广泛适用性、模型正确性或方法优越性表述也须根据当前工作的实际证据重新判断。当前E题要求全量结果，不照搬样本论文只展示部分结果的做法。

三篇全文总页数为52—61页，正文区间约36、46、47页，说明全文页数受前置页、附录和任务类型影响。总论文的47—51页预算来自当前题目的必要内容、已有材料冗余和规定字号，不是对这三篇求平均所得。

参考过程中不复制其摘要、公式推导、图片或方法命名；仅借鉴可复用的组织规律。若后续实际采用某篇的方法，再在正文方法处正式引用。
