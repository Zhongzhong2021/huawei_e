# 固定配方下关闭连续缺失增强

本实验检验：在完整12层文本编码器、音视频融合、逆频率类别权重和4轮训练保持一致时，能否关闭训练期连续缺失增强，简化训练流程并保持分类与回归表现。

## 配对设计

复用联合缺失实验的三折视频分组、拟合样本、标准化参数、原增强模型和46组评价掩码。每折只新训练一个无增强模型。两组从相同预训练参数和随机种子开始，样本顺序与增强随机数分离；优化器、批量、类别权重、训练轮数和推理口径一致。旧对照的源码、数据、权重与预测文件经过校验，复用对应明确的既有实验结果。

3395条附件2训练样本各作为折内评价样本一次；拟合与评价视频互斥。评价包含完整输入、9种单模态连续缺失，以及共同缺失的4种比例、3种形状、3个掩码种子，共46种场景。共同缺失的低度为10%/20%，中度为30%，重度为50%。每种场景报告Accuracy、Macro-F1、MAE与Pearson。

## 训练前固定的判定

本次目标是检验简化是否成立。原实验的提升门槛同时保留为单独报告项，两者分别判断。

简化条件要求：完整输入的F1下降不超过0.01、Accuracy下降不超过0.01，单模态F1下降不超过0.01，各共同缺失分组F1下降不超过0.005；各组MAE增加不超过0.02。低、中度综合分数平均下降不超过0.002，至少两折满足同一分数容差。分数仍为0.5×F1＋0.5×(1−MAE/6)。

进一步对视频分组配对Bootstrap进行2000次重采样，要求完整输入、单模态、低度、中度、重度及低中度合计的F1与MAE差值95%区间均落在对应单侧容差以内。区间用于检验能否支持性能保持；“差值区间跨零”本身不能证明等效。该证据以固定模型与扰动为条件，未覆盖训练随机性和反复选择的不确定性。

只有内部简化条件全部成立，才在全部训练集上进行种子42、2026、3407的三组配对训练，并用同一条件确认。候选与门槛在运行前固定，不根据结果重新调整。附件3标签、跨附件恢复内容和测试集不参与本实验。

## 运行

在`问题2`目录中，使用已安装`requirements-retrain.txt`的CUDA环境：

```bash
OPENBLAS_NUM_THREADS=4 OMP_NUM_THREADS=4 PYTHONPATH=src \
python scripts/run_no_augmentation_study.py \
  --reference /workspace/q2-joint-study-20260927 \
  --aligned /workspace/data/附件2-数据集特征文件/aligned_50.pkl \
  --pretrained /workspace/q2-pretrained/converted/bert_base_uncased.pt \
  --output /workspace/q2-noaug-study-20260927

OPENBLAS_NUM_THREADS=4 OMP_NUM_THREADS=4 PYTHONPATH=src \
python scripts/report_no_augmentation_study.py \
  --run /workspace/q2-noaug-study-20260927 \
  --aligned /workspace/data/附件2-数据集特征文件/aligned_50.pkl \
  --output /workspace/q2-noaug-report-new
```

运行与报告输出目录必须不存在。基线目录由[联合缺失实验](联合缺失对照实验.md)生成，模型及逐条预测保存在仓库外；导出报告保存汇总、配对区间、逐场景指标、训练配置与文件校验值。

已完成的三方案比较、区间图和全部场景结果见[实验结果](no_augmentation_study/README.md)。区间图由`plot_augmentation_comparison.py`读取两份`analysis.json`生成。
