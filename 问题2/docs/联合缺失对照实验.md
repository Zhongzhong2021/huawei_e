# 联合缺失增强对照实验

本实验检验一个候选：在原单模态连续缺失增强中加入三模态共同缺失。固定协议见 [`joint_missing_study.json`](../configs/joint_missing_study.json)。输入结构依据来自[附件关联核查](../../数据关联核查/问题2处理建议.md)。

## 对照变量

骨干、完整词表、逆频率分类权重、优化器、批量32、固定4轮及0.7增强概率保持一致。原增强为随机一种模态的连续缺失；候选在发生增强时，以1/2概率采用原增强，其余等概率采用共同连续、共同分散、共同短段缺失。

原单模态分支使用10%/30%/50%比例；共同分支使用10%/20%/30%/40%/50%。短段生成器在每四个有效位置内至多选择两个连续位置，邻块边界可合并，最终相邻段最长4个位置。各形状均保持指定移除数量，空输入不增加观测。随机位置来自训练样本自身，未复制专项样本掩码。

两组分别使用相同的模型初始化种子和样本排列种子，增强随机流与排列随机流分离；因此两组增强抽样次数不同不会改变下一轮训练顺序。这一控制对两组同时启用，原配方默认随机路径保持不变。

主对照中两组都使用未知词不可观测的口径，单独衡量训练增强的影响。训练时通过观测掩码排除位置，与推理时将占位词元、音视频共同置为不可观测产生相同的模型输入效果；此等价性已进行模型级测试。

## 内部选择与确认

仅在附件2的3395条训练样本中，按视频进行三折分层分组划分。每折标准化参数、类别权重只用拟合子集估计。两组每折固定训练4轮，均用种子42；不按开发集选择训练轮数。

每个模型评价46个条件：完整输入1个、原单模态连续缺失9个，以及共同缺失的4个比例×3种形状×3个位置种子。所有对照共用实际掩码。比例10%/20%归为低度，30%为中度，50%为重度。

选择分数为低、中度共同缺失的 `0.5×平均F1 + 0.5×(1−平均MAE/6)`，重度场景不进入该分数。三折平均分数至少增加0.002，且至少两折增加，同时满足：

| 比较范围 | 允许的最大下降／增加 |
|---|---:|
| 完整输入F1、Accuracy | 各下降0.01 |
| 完整输入MAE | 增加0.02 |
| 原单模态平均F1／MAE | 下降0.01／增加0.02 |
| 低、中、重度共同缺失各组F1／MAE | 下降0.005／增加0.02 |

只有内部比较通过，才冻结候选，并在完整训练集上对两组分别使用42、2026、3407三个种子训练、在官方验证集确认。三种子均值采用同一保护条件和分数阈值，至少两个配对种子增加。部署种子预先固定为42。

本次范围为一个候选、6次内部训练，条件满足时最多追加6次确认训练。附件3仅提供输入结构线索；测试划分和专项标签不用于评价或选择。官方验证此前已用于研究，本次结果属于固定设计下的条件比较。

## 运行与结果核对

在“问题2”目录和已有GPU环境中运行：

```bash
export PYTHONPATH="$PWD/src"
python -m q2v3 audit
python scripts/run_joint_missing_study.py \
  --aligned /workspace/data/附件2-数据集特征文件/aligned_50.pkl \
  --pretrained /workspace/q2-pretrained/converted/bert_base_uncased.pt \
  --output /你的路径/新实验目录
python scripts/report_joint_missing_study.py \
  --run /你的路径/新实验目录 \
  --aligned /workspace/data/附件2-数据集特征文件/aligned_50.pkl \
  --output /你的路径/新结果报告
```

实验目录记录开始时间、固定协议、源码和数据哈希、拟合及评价样本ID、标准化参数、实际掩码、逐轮记录、模型与逐样本预测。已有目录拒绝覆盖。结果程序逐表复算指标，并以2000次视频分组配对Bootstrap给出F1和MAE差值区间。

内部评价在各折内独立重采样视频，再等权平均三折差值；确认评价对三个训练种子使用相同视频重采样，再平均种子差值。区间条件于已拟合模型和固定缺失位置，不包含重新训练、模型选择的不确定性，分项区间未作多重比较校正。
