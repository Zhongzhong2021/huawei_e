# 问题2论文文档与模型迭代进展

当前正式模型是第四轮 `balanced_inverse`：完整预训练词表、12层文本编码器、音视频融合、连续缺失训练和逆频率分类权重。第五轮尚无通过确认的新模型，不能替换第四轮预测或在论文中报告为最新提升。

## 队友阅读顺序

1. [第三轮完整论文素材](round3/reports/E题问题2局部模态缺失鲁棒预测论文素材.md)：用于问题重述、假设、符号、掩码、模型、训练与评价等完整方法正文。[可编辑Word](round3/reports/E题问题2局部模态缺失鲁棒预测论文素材.docx)有17页、16个可编辑公式。
2. [第四轮类别平衡实验补充](round4/reports/E题问题2第四轮类别平衡实验与论文补充.md)：用于更新目标函数、最终模型、主结果和类别权衡。[可编辑Word](round4/reports/E题问题2第四轮类别平衡实验与论文补充.docx)有8页、4个可编辑公式、8张表。
3. [当前迭代效果与未完成事项](当前迭代效果.md)：区分已确认提升、性能代价及第五轮探索状态。
4. [第五轮已完成部分的论文补充](round5/reports/E题问题2第五轮延后加权实验与论文补充.md)：包含已复算的负面对照、2组配对图与未完成状态；本次先提供Markdown，Word尚未生成及验收。另见[检查点保护核验](检查点保护与第五轮关闭说明.md)。

第三轮正文中的“最终模型”是该轮历史模型。整合总论文时，应保留其结构定义，并用第四轮补充更新分类损失、当前成绩和附件3预测来源，不可把两轮结果混成一个模型。论文图号和公式号需要在总稿中重新统一。

## 已同步的材料

- `round3/figures/`、`round4/figures/`：共12组论文图，含SVG、PDF与600 dpi PNG，Markdown图片链接可在仓库内直接解析。
- 两轮的 `reports/`：Word、Markdown、LaTeX公式源码、结构化表格及正文来源记录。
- `round3/evidence/`、`round4/evidence/`：原文档验收、冻结记录、确认指标与统计协议。Word未重新排版；同步时验证其哈希与既有逐页验收记录相同。
- `iteration_metrics.json`：从三种子确认记录自动复算的均值、样本标准差、逐种子数值及差值。
- `round5_snapshot/`：第五轮截至本次同步的协议、开发记录、控制实验和未完成运行日志。它不是完成验收的第五轮交付包。
- `round5/`：后续关闭记录、70组逐样本预测复算的审计、已完成候选的科研图与论文补充。未完成候选不填补均值，也不视为负面实验结论。
- `sync_manifest.json`：每个同步源文件的相对来源、大小和SHA256，防止同名文件混用。

第一轮[报告](round1/reports/E题问题2解决方案与实验报告.md)及[Word](round1/reports/E题问题2解决方案与实验报告.docx)、第二轮[报告](round2/reports/E题问题2第二轮优化方案与实验报告.md)及[Word](round2/reports/E题问题2第二轮优化方案与实验报告.docx)仅保留为历史记录，不能替代当前模型说明。历史报告中关于体积与量化的内容不是本阶段的模型约束。

## 同步与复核

在PowerShell 7中从“问题2”目录执行：

```powershell
./scripts/sync_documents.ps1 -SourceRoot /完整实验导出目录/e_q2
```

可额外传入 `-Round5Root` 保存第五轮日志快照。脚本不训练、不访问测试集、不改写原始文档；遇到目标已有不同内容即停止，须人工审查队友修改后再处理。第五轮快照可能随实验发展变化，不应无审查覆盖当前快照。

Git同步文档、科研图形、汇总证据及代码；原始赛题PKL、模型权重和完整逐样本预测档案仍按[代码运行说明](../README.md)另行共享。本目录不是可独立复训的完整实验数据包。附件3没有标签，30条预测覆盖检查不代表已知准确率。
