## 同步与复核

在PowerShell 7中从“问题2”目录执行：

```powershell
./scripts/sync_documents.ps1 -SourceRoot /完整实验导出目录/e_q2
```

可额外传入 `-Round5Root` 保存第五轮日志快照。脚本不训练、不访问测试集、不改写原始文档；遇到目标已有不同内容即停止，须人工审查队友修改后再处理。第五轮快照可能随实验发展变化，不应无审查覆盖当前快照。

Git同步文档、科研图形、汇总证据及代码；原始赛题PKL、模型权重和完整逐样本预测档案仍按[代码运行说明](../README.md)另行共享。本目录不是可独立复训的完整实验数据包。附件3没有标签，30条预测覆盖检查不代表已知准确率。
