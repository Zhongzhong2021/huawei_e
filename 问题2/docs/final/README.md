# 问题2：定版方法与结果

采用完整12层预训练文本编码器、音视频融合、编码前观测掩码、逆频率类别权重、连续缺失增强和分类—强度双任务学习。使用附件2对齐版，固定种子42训练4轮。定版权重、验证图表及附件3预测统一对应`q2-final-span-seed42-v1`。

## 方法与求解

1. 读取`text_bert`、`audio`、`vision`，核查形状、整数词元、有限性、有效长度和填充；未知词占位采用`retain`口径。
2. 只用训练集的可观测音视频位置拟合标准化参数，验证与专项输入共用这些参数。
3. 以有效位置、原始观测状态与模拟缺失共同构造掩码，在编码前屏蔽缺失内容；文本由12层预训练编码器表示，音视频采用掩码汇总，再融合预测。
4. 以0.7概率对一个模态生成连续缺失，比例从10%、30%、50%等概率选择；使用逆频率加权交叉熵与Huber损失，权重1∶1。
5. AdamW训练4轮，有效批量32，编码器学习率2×10⁻⁵，其余参数5×10⁻⁴，梯度裁剪1。输出负向／中性／正向概率及[-3,3]强度。

完整数学表达、网络结构、参数、求解、消融与结果说明以[论文问题2正文](../../../Paper/manuscript/question2.md)为准。

## 验证与缺失规律

728条验证样本的完整输入结果：Accuracy **0.6195**、Macro-F1 **0.6102**、MAE **0.5861**、Pearson **0.6712**。九类单模态连续缺失的平均Macro-F1为**0.5975**，平均MAE为**0.5978**。

共评价46个条件：完整输入1个；三模态×三个比例的随机连续缺失9个；三模态×三个比例×前／中／后／多个短段36个。全部四项指标见[验证结果](validation_metrics.json)，[比例响应](missing.pdf)、[位置与形状响应](missing_shapes.pdf)和[错误分析](errors.pdf)与定版权重一致。位置与长度按有效特征索引定义，不将比例直接解释为秒数。

负向、中性、正向F1分别为0.6615、0.4815、0.6876。184条中性样本中104条识别正确；中性与有倾向情感的混淆是主要分类难点。真实负向样本的强度MAE较高。分类与回归输出分别评价，详细计数见[错误统计](diagnostics.json)。

## 方法选择依据

配方选择阶段的词表、模态、编码深度与类别加权实验保留为开发证据；三种子历史结果与本定版权重分别注明。进一步的固定4轮对照覆盖混合共同缺失增强与关闭增强：

- [混合增强](../joint_missing_study/README.md)改善重度共同缺失，但低、中度综合收益未达到预设采用门槛。
- [关闭增强](../no_augmentation_study/README.md)使重度共同缺失F1下降、含共同缺失的46个配对场景平均MAE均增加，未通过性能保持条件。
- [观测口径对照](../retraining_seed42/README.md)分别报告保留与屏蔽未知词的收益和代价，专项推理固定采用`retain`。

这些实验支撑保留连续缺失增强，不把当前方案表述为所有场景的最优模型。定版依据为已完成的建模、验证和任务覆盖；测试集追加比较不作为本次定版步骤。
