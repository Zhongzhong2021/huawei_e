# 问题2固定配方重训

使用附件2训练集重新拟合种子42模型，固定训练4轮。输入配置见 [`retrain_seed42.json`](../configs/retrain_seed42.json)，模型结构、优化器、类别权重和连续缺失增强沿用已保存配方。`confirmed_seed42.json` 中的 `max_epochs=6` 是原开发上限，实际训练轮数由新配方明确固定为4。

此入口直接读取通用 BERT 初始化权重，无需原任务模型。输出为独立的新模型版本，保存数据、代码、初始化来源、环境和模型校验值。

## 环境与初始化

在“问题2”目录执行，使用独立 Python 3.10 环境和支持 BF16 的 CUDA GPU：

```bash
python -m pip install torch==2.8.0 --index-url https://download.pytorch.org/whl/cu128
python -m pip install -r requirements-retrain.txt
export PYTHONPATH="$PWD/src"
python -m q2v3 audit
```

初始化使用 [BERT 固定版本](https://huggingface.co/google-bert/bert-base-uncased/tree/86b5e0934494bd15c9632b12f734a8a67f723594)，遵循 Apache-2.0 许可。以下变量指向本机实际路径；转换、训练和评价输出目录均须尚不存在。

```bash
Q2_WORK=/workspace/q2-pretrained
Q2_RUN=/workspace/q2-retraining-20260926
Q2_ALIGNED=/workspace/data/附件2-数据集特征文件/aligned_50.pkl
Q2_SPECIAL=/workspace/data/附件3-模态缺失特征样本/对齐版本
mkdir -p "$Q2_WORK/bert-base-uncased"
curl -fL --retry 3 \
  https://huggingface.co/google-bert/bert-base-uncased/resolve/86b5e0934494bd15c9632b12f734a8a67f723594/model.safetensors \
  -o "$Q2_WORK/bert-base-uncased/model.safetensors"
python scripts/prepare_bert_initialization.py \
  --safetensors "$Q2_WORK/bert-base-uncased/model.safetensors" \
  --output "$Q2_WORK/converted"
```

转换器核对原文件 SHA-256，将 LayerNorm 的 `gamma/beta` 映射为 `weight/bias`，校验12层编码器的197个初始化张量及序列化一致性。预测阶段只需要最终模型与标准化参数。

## 训练

```bash
python scripts/retrain_seed42.py \
  --aligned "$Q2_ALIGNED" \
  --pretrained "$Q2_WORK/converted/bert_base_uncased.pt" \
  --output "$Q2_RUN"
```

3395条训练样本用于拟合模型、类别权重和音视频标准化参数；728条验证样本用于固定训练结束后的评价。程序检查训练/验证样本标识互斥，保持原始观测掩码，在标准化后将缺失位置归零。该入口仅处理训练和验证两个划分。

有效批量为32，GPU训练采用 BF16 自动混合精度，评价采用 FP32，关闭 TF32。显存不足时使用保持有效批量和加权损失分母一致的梯度累积。第4轮权重保存为 `final/model.pt`，训练集统计量保存为 `final/scaler.npz`。

## 评价

```bash
python scripts/evaluate_retrained.py \
  --run "$Q2_RUN" --aligned "$Q2_ALIGNED" --special "$Q2_SPECIAL" \
  --report /你的路径/新评价报告
```

评价包括：

1. 完整输入及45种缺失场景，覆盖模态、位置和长度；保存全部预测和实际掩码。长度单位为对齐后的有效特征位置。
2. 13个场景下 `retain` 与 `mask_unk` 两种未知词观测口径，共26组结果；使用相同扰动位置，保存逐样本预测，以2000次视频分组配对 Bootstrap 计算 Macro-F1、MAE 差值区间。
3. 附件3全部30条预测，以及单条/批量、重载、CPU/GPU数值一致性检查。
4. 从72张预测表重新计算 Accuracy、Macro-F1、MAE、Pearson，与汇总记录核对。

Bootstrap 区间反映固定模型、固定扰动下的视频抽样变化；各场景区间未作多重比较校正。专项样本没有真实标签，报告输出覆盖和数值一致性。原种子42指标与新模型指标分别列示，两种占位口径的比较结果用于方法诊断。

完整运行目录保存权重、标准化参数、场景掩码和逐条预测；报告目录保存汇总结果、30条专项预测、环境与来源记录。已有目录会被拒绝，重新执行时使用新路径。
