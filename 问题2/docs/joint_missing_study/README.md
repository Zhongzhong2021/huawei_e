# 联合缺失增强：三折对照结果

完成原连续增强与混合联合增强的三折视频分组对照，共6次固定4轮训练、276组评价。候选在重度共同缺失下改善较明显，在低、中度共同缺失上的综合收益未达到预设采用门槛，当前模型继续使用已核验版本。

## 三折平均结果

下表为附件2训练集内部三折的折均值。前次重训的Macro-F1 0.6102对应728条官方验证样本，两次评价集合不同。两组在本实验中采用相同的未知词屏蔽口径，表中差值衡量训练增强的作用。

| 场景 | 原增强F1 | 联合增强F1 | 原增强MAE | 联合增强MAE |
|---|---:|---:|---:|---:|
| 完整输入 | 0.6282 | 0.6266 | 0.6042 | 0.6057 |
| 原单模态连续缺失 | 0.6105 | 0.6107 | 0.6230 | 0.6237 |
| 低度共同缺失（10%/20%） | 0.6037 | 0.6053 | 0.6286 | 0.6296 |
| 中度共同缺失（30%） | 0.5805 | 0.5854 | 0.6538 | 0.6552 |
| 重度共同缺失（50%） | 0.5300 | 0.5433 | 0.7047 | 0.6998 |
| 低、中度共同缺失合计 | 0.5960 | 0.5987 | 0.6370 | 0.6381 |

低、中度共同缺失平均F1增加0.0027，95%视频分组配对区间为[-0.0017, 0.0071]；MAE增加0.0011，区间为[-0.0032, 0.0053]。这部分收益仍不明确。

50%共同缺失的F1增加0.0133，区间为[0.0085, 0.0182]；MAE下降约0.0050，其区间约为[-0.01013, -0.00006]。这些是固定模型与扰动下的分项区间，未作多重比较校正，也不包含重新训练的不确定性。

完整输入F1下降0.0016，MAE增加0.0015；原单模态场景变化较小。逐场景Accuracy、F1、MAE、Pearson见[全部场景指标](condition_metrics.json)，分组汇总与配对区间见[分析结果](analysis.json)。

## 按固定规则作出的决定

低、中度综合分数从0.744898变为0.746152，增加0.001254，低于训练前固定的0.002门槛。三个配对折的分数差分别为-0.001073、+0.003110、+0.001726。两个折改善，全部性能保护条件通过，最低收益条件未通过。

因此，该候选保存为研究对照，按协议完成于内部选择阶段。当前模型与附件3的30条预测沿用[已核验重训版本](../retraining_seed42/README.md)。本轮没有官方验证确认成绩，也没有新的专项预测准确率。

这一结果限定于当前混合比例、增强强度及4轮训练配方，不等同于联合缺失增强在所有设置下无效。数据关联核查的实际作用是识别训练与输入结构的差距，并据此建立能够检验该差距的对照；重度场景的收益不能替代低、中度场景的证据。

## 完整性与复现

- 三折开发样本合计3395条，每条恰好作为开发样本一次，各折拟合与开发视频互斥。
- 由原始数据重新计算每折标准化参数、类别权重、归一化数组与46组缺失掩码，结果全部一致。
- 276张预测表的四项指标均独立复算一致，容差10⁻¹⁰；文件校验值保存在分析结果中。
- 2000次视频分组配对Bootstrap使用各折内部重采样，再等权平均折差值。
- 64项自动测试通过，包括原增强输出保持一致、短段边界、联合掩码、训练/推理等价性和选择规则。
