# 模型来源与复现实验说明

## 来源与适配

本交付以比赛给定的对齐版文本、音频、视觉特征完成三分类与强度预测。主模型的局部项及显式成对交互低秩形式参考 MultiBench 的多模态融合实践；本地在 `q3b/model.py` 中实现窗口、掩码、回归和原生贡献读出，并在 `q3b/ordinal_uncertainty.py` 中加入不确定性加权及比赛目标。MultiBench 采用 MIT 许可证。SELF-MM 基线借鉴 MMSA 中的自监督单模态监督思路，由 `q3b/selfmm_adapter.py` 等写成比赛输入适配实现。TETFN 基线使用随包 `third_party/MMSA/` 保留的 TETFN 网络组件，经 `q3b/tetfn_source_adapter.py` 接入统一输入、训练与验证选择。MMSA 采用 MIT 许可证。BERT `bert-base-uncased` 的配置与原始预训练参数按 Apache-2.0 使用；交付包仅含配置和已训练任务检查点。

这些基线均改动了原始模型的数据预处理、目标/损失、模型接线、优化或验证策略，目标是**同一比赛任务上的可运行对照**，不是原论文严格复现。许可文本与代码出处见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)、`../licenses/` 与 `../third_party/MMSA/LICENSE`。本项目没有把上游其他任务的报告分数当作本比赛结果。

## 冻结实验

固定随机种子为 17，最多训练 20 轮；该次主模型实际训练 9 轮，验证集 Macro-F1 目标选择第 5 轮及 `neutral_bias=-0.4`。SELF-MM 与 TETFN 的随包基线是各自原验证 Macro-F1 最优版，分别为第 3、1 轮；其阈值策略见 `weights/<模型>/policy.json`。每轮在 valid 上为 Macro-F1、Accuracy、MAE 三个目标分别选策略并保留最佳检查点；任一目标刷新就重置四轮早停计数。优化器为 AdamW，BERT 编码器与其他参数使用配置中的不同**恒定**学习率，无学习率调度；主模型配置中的编码器学习率 `2e-5`、其余 `3e-4`。每次训练内的轮次和策略仅由验证集选择；最终将不确定性方案定为主模型时，综合了已有验证、测试、附件4公开源标签核验与解释需求。这是测试结果已暴露后的探索性方案比较，不属于新的盲测。冻结结果可核对 [model_comparison.csv](../results/model_comparison.csv)、`../results/<模型>/metrics.json` 和 `../weights/<模型>/selection.json`。

主模型验证集 Accuracy 0.6511、Macro-F1 0.6323、MAE 0.5397；测试集分别为 0.6864、0.6493、0.6006。SELF-MM 测试 Macro-F1 0.6389；TETFN 测试 Macro-F1 0.6285。全部指标为冻结策略对应的最终预测值。`results/` 还保存逐样本验证/测试/附件4预测和主模型原生解释；[20条解释卡](../results/附件4_全20条解释卡.md)融合了已有媒体映射供阅读。附件4公开来源标签的20条中**没有中性样本**，且有**5条与附件2测试集重复**；因此附件4表现不能单独衡量中性识别能力，也不能当作独立测试集。论文 Word 文件位于 [paper/](../paper/)，`build_paper.py` 可用随包结果重生。

## 推理复现与训练复现的区别

推理时 `run.py` 用随包 BERT `config.json` 建结构，并严格加载 `weights/<模型>/best.pt` 中**完整任务状态**，无网络访问、无原始预训练 BERT 大权重。三份检查点合计约 1.3 GB，已上传 Git LFS；克隆后要 `git lfs pull`，或用完整 `tar.gz` 获取。交付包超过三题合计 50 MB 的比赛附件限制，目前不能按原样作为合规附件提交。

重新训练须自行下载公开的 `bert-base-uncased` 固定 revision `86b5e0934494bd15c9632b12f734a8a67f723594` 的 `config.json` 与单文件 `model.safetensors`。该来源与 revision 记录在原工程的 BERT 来源清单中。先在可联网机器下载到本地，再将该目录搬到离线训练机。

```bash
python -m pip install 'huggingface_hub==1.28.0'
REVISION='86b5e0934494bd15c9632b12f734a8a67f723594'
REVISION="$REVISION" python - <<'PY'
import os
from huggingface_hub import snapshot_download
snapshot_download(
    repo_id="google-bert/bert-base-uncased",
    revision=os.environ["REVISION"],
    allow_patterns=["config.json", "model.safetensors"],
    local_dir="/path/to/bert-base-uncased",
)
PY
```

将 `--pretrained "/path/to/bert-base-uncased"` 传给 `run.py train`。当前加载器支持标准 Hugging Face 单文件 `model.safetensors` 或 `pytorch_model.bin` 加 `config.json`；分片索引布局不可直接使用。若上游仓库某 revision 只提供分片权重，应选择单文件基准 revision 或自行转换成标准单文件，再核对键名。训练所需原始数据同样不在交付包内，需用户提供可信比赛 `aligned_50.pkl`。详见[详细使用指南](详细使用指南.md)。

## 改动清单与核查

相对上游，具体改动包括：① 将 MMSA/TETFN 网络接入统一对齐 `[L,768]/[L,74]/[L,35]` 输入及统一标签；② 本地实现 SELF-MM 适配而非直接运行上游训练脚本；③ 加入三目标验证检查点、类别策略校准和最终强度投影；④ 主模型加入上下文化不确定性融合、可核算单项/成对贡献与来源索引；⑤ 统一离线推理、严格权重加载及 CSV/JSONL 导出。代码来源及许可与这些修改范围相互区分。

交付测试在 Python 3.11、PyTorch 2.5.1+cu124、Transformers 5.15.1、NumPy 2.4.6 上通过：三模型附件4各 20 条 GPU 离线重放，类别和浮点预测与冻结文件完全一致；主模型解释核算最大误差约 `5.29e-7`。主模型 CPU 与 GPU 类别一致，强度最大差 `8.94e-7`，辅助值最大差约 `2.86e-6`，跨设备比较建议容差 `3e-6`。最新交付测试为 `10 passed`；三个模型还分别完成一轮真实训练（训练 3395 条、验证 728 条），所得新检查点均能严格离线重载并预测20条样本。未重做完整20轮训练，也未用烟测产物替换随包冻结权重。
