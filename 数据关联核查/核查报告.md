# 附件1—4的数据关联与异常核查

核查对象为当前原始附件文件。逐项比较样本身份、原文、词元、数值特征、标签表、两套版本及媒体内容。原始数据、模型权重和预测结果均未修改；专项样本的标签未用于恢复输入、选择模型或评价预测。

**结论：附件之间存在共同来源和部分直接重合，实际缺失表示比题目文字描述更复杂。已确认附件3存在文本占位替换与音视共同置零；附件4存在版本相关的视觉特征不可用现象，并发现15号视频与给定文本不完整对应的强线索。现有证据不能把这些现象统一归因为故意改错或投毒。**

## 1. 附件之间能直接核实的关系

| 对照 | 核实结果 | 证据 |
|---|---|---|
| 附件1 → 附件2 | 100条中18条直接重合，11条位于训练集、7条位于测试集 | video_id与clip_id相同；原文和情感强度一致 |
| 附件3 → 附件2 | 两套版本均定位到01、14、24、25号，共4条；均对应附件2测试集 | 保留的音视数值逐项匹配；未对齐版原文也一致。对齐版允许float64转float32的正常精度变化 |
| 附件4 → 附件2 | 03、07、08、12、15号，共5条；均对应附件2测试集 | 原文、连续文本特征、BERT三路输入、音频和视觉特征全部一致；两套版本分别检查 |
| 附件3/4 → 附件1 | 未找到原文完全相同的条目；附件4也没有与附件1字节相同的视频或解码后相同的单声道16 kHz音轨 | 原文与媒体摘要全量对照 |

附件1不是附件2—4全部样本的原始素材库。附件3另26条、附件4另15条未在附件2的4850条中找到保留特征完全匹配的参考，不能据此判定它们被替换或损坏。

上述4条和5条均来自附件2测试集，而非训练集、验证集。它们与基础测试结果存在样本重合，不能作为额外独立测试样本重复累计。此处只核查身份与特征，不回填专项标签。

## 2. 附件3：确认存在占位替换和共同位置缺失

对未对齐版提供的原文重新执行同一词表的BERT分词，与对齐版词元逐项比较：

- 27/30条样本共131个词元发生变化，变化全部是原词元被替换为编号100，即`[UNK]`。
- 131个位置的音频、视觉向量同时全零；文本注意力掩码仍为1，类型编号保持一致。
- 01、05、10号没有这类词元替换。这只说明词元比较结果，不能据此断言三条的全部特征都未受处理。
- 对能在附件2找到参考的14、24、25号，直接确认了上述词元替换以及新增音视置零；其余非零音视数值保持一致。
- 01号对齐版的三路输入与附件2参考经目标精度转换后完全一致，没有新增缺失；其未对齐版则有新增音视置零。因此，两套版本不能理解为同一缺失掩码的简单重排。

例如，24号对齐版的原序列位置1、7同时发生文本替换及音视置零；25号为位置1、5；14号为位置21、22。位置采用零基索引。这既包括连续短段，也包括多个分散位置，并且存在三模态同位置受损。

题目已明确附件3是人为构造的缺失专项集。这里可以确认的是**缺失处理与未知词占位**，不是情感标签被篡改的证据。

### 对问题2的实际影响

实测当前`问题2/src/q2/data.py`的`convert()`：上述131个位置均被记为“文本有观测”，音频、视觉则均被记为无观测。原因是文本观测条件为注意力等于1且词元编号非零，编号100满足该条件。

这并不意味着模型无法接收`[UNK]`，但说明“有数值输入”和“原词义仍可用”被合并成了一个状态。当前主要缺失试验以单模态连续区间为主，也不能完全代表专项中观察到的共同位置损伤。

问题2应优先明确未知词占位的含义，并在附件2训练、验证范围内检验通用的占位退化与多模态共同缺失处理。`[UNK]`也可能自然出现，不能把所有未知词都认定为人为破坏。对齐版推理不能利用未对齐版原文或附件2原特征把被遮蔽的内容补回。

## 3. 附件4：特征一致、视觉可用性和视频对应分别判断

20条的两套版本具有相同原文、连续文本特征及BERT输入，配套视频也逐条字节一致。

**13号：**对齐版50行视觉特征全零；未对齐版保留17行非零视觉特征。该现象说明特征可用性与处理版本相关，不能据对齐版全零推断视频没有画面或从未检测到视觉信息。现有附件不足以确定这一差异发生于哪一步处理，也不足以认定有人故意删除视觉信息。问题3目前对该样本关闭视觉贡献，符合所选对齐版的实际输入；未对齐版不能直接补入当前模型。

**15号：**特征与附件2测试样本`SKTyBOhDX6U$_$9`完全一致，但配套音轨长约7.314秒。Whisper与另一架构的Wav2Vec2 CTC模型分别在不输入参考文本的条件下识别完整音轨，均识别出父亲去世、家庭陷入经济困境的前文，随后才到“However, despite their poverty”。给定文本则从此处开始，继续描述家庭重视教育及教育改变生活。

这构成**媒体与给定文本未完整对应、可能存在剪辑边界偏移**的强线索。两个模型的共同输出仍不是人工时间真值；当前不能据此指定应平移多少秒，也不能断言是故意改错。建议人工只复听这一条完整音轨，确认给定文本后半段是否出现。原文、特征和视频均应原样保留。

[15号原视频](/workspace/data/附件4-可解释专项视频样本与特征文件/附件4-可解释专项视频样本与特征文件/对齐版本/videos/15.mp4)

**14号与15号的原因不同：**14号两个识别结果大体覆盖原文，主要存在专名、缩略词等表达差异，上一轮未通过定位还涉及局部边界支持不足；15号则出现显著的前文—当前句边界问题。不能把两条“未定位”统一解释为模型识别误差或数据破坏。

因此，问题3中原特征对预测的数值贡献与原视频中的实际证据需要分别核查。上一轮对15号保留原索引、不给出支持不足的时间定位是合理的，但其原因应明确为存在媒体内容对应疑点。

## 4. 附件1与附件2的内部检查

附件1全部100个视频可读取音轨，其中`-mJ2ud6oKI8$_$1`和`-mJ2ud6oKI8$_$2`解码后的音频全零。该事实支持按无有效音频信号处理，但不能单凭全零确定是人为静音、源素材问题还是加工异常。

`label-100.xlsx`另有“修复说明”工作表，说明按video_id与clip_id筛选并将ID写为文本，避免以减号开头的ID被Excel解释为公式。这是编号格式修复的说明，不能解释为故意改错标签。

附件2两套版本的4850个ID及划分顺序相同，原文、BERT输入、连续文本特征和标签一致。对齐版逐项与4850行Excel核对，原文、划分、强度、类别及极性符号未发现矛盾；按原文重新分词也与BERT输入一致。四类数值字段均未检出NaN或无穷值，未发现重复ID。

附件2对齐版有153条视觉数组全零，未对齐版有38条；后者均包含在前者中，另115条仅在对齐版全零。这进一步说明，全零视觉特征不能统一视为专项集新增的人为破坏。

音轨实际长度与容器声明长度在部分视频中不一致，定位应继续采用实际解码信号与帧时间。元数据时长差异本身不能证明内容遭到恶意修改。

## 5. 对当前解答的结论

1. **问题1：**现有按实际信号、有效时序、缺失掩码和分级定位处理的方向合理；附件间关联可以用于核查来源，不能用别的附件替换题目给定素材。
2. **问题2：**发现了需要实质审视的未知词占位及三模态共同缺失口径。仅检查全零并不足以描述当前专项输入，不能继续笼统认定现有缺失说明已覆盖所有情况。
3. **问题3：**保留对齐版13号的视觉缺失处理；15号的解释须区分特征贡献与存在对应疑点的配套视频。其余定位支持不足项仍需按具体证据区分原因。
4. **故意改错或投毒：**附件3的缺失构造有题目明示与数值证据；其他现象目前只能确认为可用性差异或对应异常，缺少作者意图及加工过程证据。

## 核查材料与运行

- `feature_comparison.json`：两套附件2全量结构检查，附件1/3/4关联及逐字段差异。
