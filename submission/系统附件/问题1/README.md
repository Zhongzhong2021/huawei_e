# 问题1：多模态特征提取与时序对齐

- [问题1正文稿](问题1正文稿.md)：方法、数学定义、实验结果、典型图示和100条样本汇总。
- [复现运行说明](复现运行说明.md)：环境、固定模型、生成命令、数据读取与核验。

| 目录 | 内容 |
|---|---|
| `data/features/` | 100条样本的原生特征、时间位置与掩码 |
| `data/multigranular_alignment/` | 词级、词组级对应及全量汇总 |
| `data/temporal_index/` | 音视频物理时间索引 |
| `scripts/`、`config/`、`tests/` | 处理代码、配置与测试 |
| `研究/发音竞争/` | 发音补充、局部省略检验、逐词状态及对应代码 |

通过`multigranular_reader.Dataset`读取正式关系：`sample.word(i)`查询词，`sample.phrase(k)`查询词组，`sample.window(a,b)`查询时间窗口，`Dataset.batch`返回批量数据与有效性掩码。运行示例见运行说明。

1932个原词中，1397词有词级候选，71词仅有词组候选，464词未确定。候选覆盖率为75.98%。发音补充候选独立保存；画面与人脸特征表示同期观测，说话者身份标记未知。
