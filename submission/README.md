# 提交材料

| 文件 | 用途 |
|---|---|
| [论文.pdf](论文.pdf) | 单独提交论文 |
| [系统附件.zip](系统附件.zip) | 约25.8MB，含三问代码、问题1全量特征、预测结果与运行说明 |
| [系统附件/](系统附件/) | ZIP的展开副本，便于查看代码、特征和结果 |
| [网盘资源](网盘资源/) | 上传到百度网盘的模型权重和解释画面 |
| [网盘下载说明.txt](网盘下载说明.txt) | 待填写的网盘链接与提取码，附件ZIP中也有一份 |

将`网盘资源`整个文件夹上传百度网盘，填写下载说明，再用填写后的文件替换`系统附件.zip`内同名文件即可。说明文件可直接填写链接和提取码。

提交论文PDF和系统附件ZIP。接收者按附件内README运行；下载的资源包解压到系统附件根目录，自动合并到对应目录。

修改展开目录后，提交前需将其内容重新打包为`系统附件.zip`。只填写网盘链接时，修改展开目录中的`网盘下载说明.txt`即可。
